## 🎨 Features Showcase

### Core Features
1. **Add Tasks**: Input with validation and "Agregar" button
2. **Task List**: Display with custom checkboxes
3. **Complete Tasks**: Click checkbox to mark/unmark
4. **Delete Tasks**: Individual delete buttons with trash icon
5. **Counter**: Shows "X pendientes" and "Y completadas"
6. **Filters**: Three buttons (Todas, Activas, Completadas)
7. **Clear Completed**: Button to remove all completed tasks
8. **Persistence**: All tasks saved in localStorage

- Beautiful gradient background (purple/blue)
- White card container with shadow
- Custom animated checkboxes
